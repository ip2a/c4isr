# C4ISR

A [Paseo](https://paseo.sh) agent observability plugin: view session results, timelines, usage and tokens, scheduled runs, plus optional smart analysis and turn summaries — from one host.

## Install

```bash
paseo plugin add git:ip2a/c4isr
```

After install, run `paseo plugin ls` and confirm id is `c4isr` with status `running`.
